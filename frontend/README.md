# День Программиста 2026

Лендинг регистрации на московский фестиваль информационных технологий от Студсовета факультета ИУ МГТУ им. Н.Э. Баумана.

## Стек

- **React 19**
- **Vite 8**
- **MobX**
- **Zod**

## Установка

```bash
bun install
```

## Разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## API

Форма отправляет `POST {VITE_API_URL}/api/registrations`.
